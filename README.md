Atividade Prática – Retornando HTML e Trabalhando com Parâmetros em Rotas

Catálogo de Heróis

Este projeto foi desenvolvido como uma atividade prática utilizando Node.js e Express.

O objetivo é criar páginas HTML para apresentar as empresas Marvel e DC Comics e alguns de seus personagens. Também foi criada uma rota que recebe dois parâmetros pela URL: o nome da empresa e o nome do personagem.

Tecnologias utilizadas
Node.js
Express
JavaScript
